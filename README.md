### What v1.0 was

A six-person university course project, built in 2024: a React frontend (this
repository) and an Express backend
([`tourney-backend`](https://github.com/waleedhussein4/tourney-backend), also
archived).

Contributors: Waleed Hussein, Haytham Duwaji, Jad Zeid, Hamza Matar,
Jad El Murr, Soumi.

### What v2.0 is

A solo rewrite on the same stack, in one repository: the server re-architected
around modules, zod validation, and transactions for every credit movement; the
client rebuilt on React Query with no full-page reloads; a design system with
original artwork; 209 tests; and a $0 always-on deployment.

The old deployment this README used to link to is gone. Use
**https://tourney-host.vercel.app**.
